# JobTrack

A personal job application tracker for organizing roles, statuses, notes, and next steps.

Built as a portfolio project by Carl Joshua De Jesus.

## Features

- Add, edit, and delete job applications
- Track status: Wishlist, Applied, Interviewing, Offer, Rejected
- Search by company, role, or location
- Filter by status
- Dashboard stats
- Data saved in browser `localStorage` (no backend required for v1)

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually http://localhost:5173).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build
